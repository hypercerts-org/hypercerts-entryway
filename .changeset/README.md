# Pending release notes

Add a descriptively named Changeset for an operator-visible change to the private
`hypercerts-entryway` package. Explain the behavior and any required operator action.
Use the [writing skill](../.agents/skills/writing-changesets/SKILL.md) and
[managed authoring/version workflow](../RELEASING.md).

Changesets generates `CHANGELOG.md` when version preparation is explicitly requested.
Do not put test results, scanner triage or execution ledgers here.
